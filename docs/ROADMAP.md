# Veridium roadmap

Ideas to build once the core profile → roster → application loop is deployed and has real users.
Status reflects what's in the code today (October 2026).

| Idea | Description | Why it matters | Status |
|---|---|---|---|
| **Player directory / search** | Orgs browse and filter players by game, rank, region and role, not just react to applicants on a posted vacancy. | Lets orgs scout proactively, closer to how recruiting really works beyond job postings. | Built: filters + "Looking for team" |
| **Notifications** | On-site notifications for new applicants, application accepted/rejected and other activity, instead of checking back by hand. | Makes the application flow feel alive for both players and orgs. | Built: on-site bell. Next: email notifications (needs an email service) |
| **Org verification / profile page** | A public org profile (history, current roster, a manually confirmed "verified" badge) so players can check an org is legitimate before applying. | Protects players from fake or scam postings once applications are public. | Built: About, roster history, staff-granted badge |
| **Follow / connections** | Players and orgs follow each other, with follower counts and a feed of activity from who you follow. | Gives people a reason to open Veridium regularly, not only when job-hunting or recruiting. | Built: follows, counts, Following feed |
| **Tournament / team history as a credential** | Self-reported team history first; later, tournament results through a tournament-organizer portal, as separate verification tiers alongside Riot data. | Strengthens a profile's credibility beyond rank and win rate. | Built: team history (Veridium-verified + self-reported). Next: tournament-organizer portal |
| **Friends / contacts sync** | On sign-up, connect Discord or a game client's friends list and see which friends are already on Veridium. | An invite loop like LinkedIn's address-book sync, pointed at gaming social graphs. | Blocked: needs a Discord application (OAuth credentials), and Riot Sign On needs an approved Riot production key |
